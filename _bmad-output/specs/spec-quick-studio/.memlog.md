- (constraint) Three-ring trust model governs all (AD-1, adopted spine): data flows outward only, capability never inward. Every unit is Core/UI/Sandbox; no feature builds a path letting less-trusted code reach DB/credentials/keys.
- (constraint) Executable JS from LLM-generated MDX runs ONLY in a cross-origin iframe, pure-render, fed one-way (AD-3). allow-scripts without allow-same-origin, CSP default-src 'none'. No host/fs/network/backend/credential/SQL. HARD PREREQUISITE for CAP-10 (PRD §11-R1).
- (constraint) All SQL runs through one Core executor, the sole risk classifier (AD-4). UPDATE/DELETE/DROP/TRUNCATE/ALTER default-deny, always confirmed; multi-statement rejected/split. A UI dialog is never the gate.
- (constraint) Credentials never written plaintext, even as fallback (AD-5). AES-256-GCM store; 32-byte key in OS keychain (Windows Credential Manager / Linux Secret Service); passphrase-derived key when no keychain.
- (constraint) Core authenticates every caller (AD-12): session capability token on every RPC + Origin/Host anti-rebinding. Loopback is not an auth boundary. Live Report authorized only as explicit second caller.
- (constraint) Only outbound channel is the user-configured Provider, called by the Core via a typed inspectable payload (AD-7). Schema-only by default; row data only via explicit, per-query, visibly-indicated opt-in (PRD §11-R5).
- (constraint) Ephemeral mode writes nothing to disk (AD-8); no daemon outlives the process. Persistent state lives under one OS-convention app dir (AD-15).
- (constraint) AI runs on the user's own Provider keys: no backend account, no hosted inference cost (PRD §11-R6 / AD-7).
- (constraint) Performance budgets are acceptance criteria, not aspirations (PRD §10): idle RAM <= ~200MB ceiling, cold start <= 2s, common UI interaction < 100ms, large results responsive via Core pagination, streaming never janks UI thread. 'Lightweight' is the identity.
- (constraint) v1 platforms = Windows + Linux (macOS out). Relational only (Postgres/MySQL). No ORM dependency (connects directly).
- (constraint) Stack/topology (HOW) is fixed in the adopted ARCHITECTURE-SPINE.md, not this kernel: full TypeScript/Bun, single-binary + npm distribution, charting split by ring (Recharts in-app / Observable Plot in sandbox), Vercel AI SDK. Downstream reads the spine for build detail.
